## ✳️ _Structure_

```
frontend/
├── app/                # Pages
│   ├── page.tsx        # Home
│   ├── chat/           # Chat interface
│   ├── not-found.tsx   # 404 page
│   └── layout.tsx      # Root layout
├── components/         # React components
│   ├── ui/             # shadcn/ui components
│   └── ...
├── lib/                # Utilities
│   └── utils.ts        # Tailwind class merge helper
├── hooks/              # Custom hooks
└── public/             # Static assets
```

---

## ✳️ _Getting Started_

```bash
cd frontend
```

```bash
pnpm install
```

```bash
pnpm dev
```
